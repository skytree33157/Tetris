# 화면 촬영과 이미지 추가

[README](../README.md) · [아이템 설명](items.md) · [검증 기록](test-results.md)

이미지는 팀원이 직접 촬영해 넣습니다. 아래 표의 경로는 권장 파일명이며, 아직 실제 이미지 파일은 없습니다. README와 아이템 문서의 해당 위치에는 주석으로 이미지 문법을 준비했습니다.

## 넣는 방법

1. 게임을 직접 실행하고 아래 표에 맞춰 촬영합니다. 바탕화면·이름 입력 등 개인정보가 보이지 않게 게임 창 중심으로 자릅니다.
2. 로컬에서 넣으려면 파일을 `docs/images/`에 저장합니다.
3. 문서의 `SCREENSHOT:` 주석에서 준비된 `![설명](경로)` 한 줄을 꺼내고, 주석 전체를 그 한 줄로 바꿉니다. 파일을 넣기 전에는 주석이라 깨진 이미지가 표시되지 않습니다.
4. GitHub에서 넣으려면 **docs/add-readme 브랜치**의 문서를 편집하고 해당 주석 자리에 이미지를 드래그하거나 붙여넣습니다. GitHub가 만든 이미지 문법을 그대로 사용해도 됩니다.
5. 문서와 이미지 파일만 문서 브랜치에서 커밋합니다. README와 `docs/items.md`는 폴더가 달라 이미지 경로도 다릅니다.
6. 검증 자료로 사용할 사진에는 [수동 확인 기록](test-results.md#수동-확인-기록)에 촬영 환경·소스 버전·확인 내용을 함께 적습니다.

README 전체에 사진을 늘어놓지 않도록 대표 사진은 본문에, 아이템별 사진은 아이템 문서에 넣습니다.

단일 사진만으로 실시간 점수 갱신·저장 지속성을 증명하지 않습니다. 변화가 중요한 항목은 전후 사진 또는 짧은 영상과 기록을 함께 남깁니다.

## 설정과 색상 모드

| 파일 경로 | 찍을 화면 | 확인할 내용 | 넣을 위치 |
|---|---|---|---|
| `docs/images/color-normal.png` | 일반 색상 모드 | 블록 색·문자와 NEXT | README의 접힌 색상 비교 영역 |
| `docs/images/color-protanopia.png` | 적색맹 모드 | 블록과 아이템이 색·패턴·문자로 구분됨 | 같은 위치 |
| `docs/images/color-deuteranopia.png` | 녹색맹 모드 | 같은 확인 | 같은 위치 |
| `docs/images/color-tritanopia.png` | 청황색맹 모드 | 같은 확인 | 같은 위치 |

가능하면 같은 화면 크기와 비슷한 블록 구성으로 찍습니다. 일반 테트로미노 S와 아이템 S는 모양과 표시 칸으로 구분해 설명합니다. 사진을 찍은 것과 색각 이상 사용자의 식별 평가를 완료한 것은 구분합니다.

## 배포 확정 후

| 권장 파일 경로 | 찍을 화면 | 확인할 내용 |
|---|---|---|
| `docs/images/package-files.png` | 압축을 푼 배포 폴더 | TFSE.exe와 아이콘·동봉 파일, 개인 경로 제외 |
| `docs/images/package-start.png` | 배포 실행 파일로 연 시작 메뉴 | 소스 실행이 아닌 패키지 기동. 실행 버전·환경은 기록에 별도 작성 |

이 두 사진은 패키징 담당자가 확정 패키지로 실행 확인한 뒤 추가합니다. 파일 목록 사진만으로 더블클릭 실행 성공을 표시하지 않습니다.

## 업로드 확인

- [ ] 사진을 넣은 위치의 `SCREENSHOT:` 주석을 실제 이미지 문법으로 바꿈
- [ ] 이미지와 설명이 같은 버전·같은 기능을 가리킴
- [ ] 이미지가 작아도 문자·점수·설정 항목을 읽을 수 있음
- [ ] 개인정보·다른 창·민감한 경로를 제외함
- [ ] GitHub 미리보기에서 이미지가 열림
- [ ] 문서 브랜치로만 커밋·푸시함
